# Home Assistant Lab

This repository documents my Home Assistant, smart home and homelab learning journey.

## Repository structure

```text
home-assistant-lab/
├── 01-setup/
├── 02-integrations/
├── 03-automations/
├── 04-projects/
├── 05-learning/
└── README.md
```

### 01-setup

Current system setup and infrastructure documentation.

Examples:
- current Home Assistant setup
- backups
- remote access
- storage

### 02-integrations

Documentation for technologies and integrations connected to Home Assistant.

Examples:
- Zigbee
- Node-RED
- other future integrations

### 03-automations

Individual Home Assistant automations.

Examples:
- adaptive lighting
- motion-based automations
- other smaller HA automations

### 04-projects

Larger projects that combine multiple technologies, automations or services.

Current projects:
- dashboard
- ESP32
- SSD migration
- timelapse backup

### 05-learning

Learning notes and study material related to Home Assistant.

Examples:
- YAML
- concepts
- experiments

## Main goals

- Improve and document my Home Assistant setup
- Build useful and reliable automations
- Learn Home Assistant architecture and troubleshooting
- Learn Zigbee, Node-RED, YAML and ESP32
- Improve Linux and networking skills through practical projects
- Build projects step by step and document both successes and mistakes

## Current setup

- Home Assistant running on Raspberry Pi 5
- SSD/NVMe storage
- Zigbee2MQTT
- Tailscale remote access
- Google Drive Backup
- RPi3 server used for additional storage and homelab tasks

## Current projects

- Timelapse backup redesign
- Dashboard improvements

- SSD migration documentation
