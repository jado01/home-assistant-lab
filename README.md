# Home Assistant Lab

This repository documents my Home Assistant, smart home and homelab learning journey.

## Main goals

- Rebuild and improve my Home Assistant setup
- Document all important steps and mistakes
- Learn Zigbee2MQTT, MQTT, Tailscale, backups and dashboards
- Migrate Home Assistant from SD card to SSD/NVMe
- Build useful automations
- Later learn Node-RED, MariaDB, YAML and ESP32 projects

## Current status

- Home Assistant is running on Raspberry Pi 5
- Static IP configured in the new home network
- Tailscale remote access is working
- Google Drive Backup is working and verified
- Zigbee2MQTT is running
- Zigbee cleanup started
- SSD/NVMe migration planned
